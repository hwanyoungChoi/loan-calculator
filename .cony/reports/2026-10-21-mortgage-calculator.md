# 주담대 한도·자기자금 계산기 최종 보고 (2026-10-21)

## 결과

매매가와 KB시세를 입력하면, 둘 중 낮은 금액을 담보 기준으로 주담대 예상 한도와 필요한 자기자금을 보여주는 모바일 우선 계산기를 만들었다. 조건별 LTV와 한도 상한을 반영하고, 매물을 저장해 비교할 수 있다. 태스크 3개를 모두 마쳤고 테스트 358개가 통과한다.

## 팀이 내린 결정

되돌리기 비싼 결정은 **검토 권장**으로 표시했다.

- [ADR-001](../decisions/001-storage.md) 매물 저장은 localStorage, 버전 필드 없이 전체 단위로 손상을 판정한다. **검토 권장**: 사용자가 다음 작업으로 부부 공유 저장(Cloudflare D1 + Access)을 요청했다. 서버 저장으로 넘어가면 이 결정을 뒤집는다.
- [ADR-002](../decisions/002-money-unit.md) 금액은 만원 정수, LTV는 정수 퍼센트로 다룬다.
- [ADR-003](../decisions/003-directory.md) 디렉토리 구조와 `@/` alias. **검토 권장**.
- [ADR-004](../decisions/004-routing-state.md) 해시 라우트는 2개, 계산 화면은 draft 하나만 본다. **검토 권장**: 매물 공유 링크(딥링크)가 필요해지면 다시 본다.
- [ADR-005](../decisions/005-cap-reference-price.md) 한도 상한 구간은 max(매매가, KB시세)로 판단한다. **검토 권장**: 10·15 대책 원문에 "주택가격(시가)"의 정의가 없어서 보수적으로 정했다.
- [ADR-006](../decisions/006-extra-costs.md) 부대비용(취득세 등)은 이번에 넣지 않는다.
- [ADR-007](../decisions/007-store-inputs-only.md) 매물은 입력값만 저장하고, 표시할 때 다시 계산한다.
- [ADR-008](../decisions/008-ui-testing.md) 화면 테스트에 @testing-library/react와 jsdom을 도입한다. tester가 반대해서 planner가 안을 수정했다.
- [ADR-009](../decisions/009-borrower-ui.md) 보유 상태는 4값 라디오 하나로 고르고, 기본값은 규제지역·무주택이다.
- [ADR-010](../decisions/010-id-generation.md) 매물 id는 `crypto.getRandomValues`로 만들고, 테스트에서 주입할 수 있게 한다.

리드가 브라우저 360×780에서 확인한 것:

- M4: 목록 스크롤 복원(1200 → 0 → 1200), 탭으로 들어오면 0
- M7: 저장 데이터 손상 시 화면
- 정렬 쿼리 유지, 시트를 Esc로 닫으면 포커스가 저장 버튼으로 돌아오고 inert가 풀림

못 한 것:

- M2: 실기기 숫자 키패드
- M3: iOS 키보드와 하단 바·저장 시트
- M5: 근거 링크가 실제로 열리는지(href만 확인)

## 남은 이슈

- 저장에 성공하면 버튼이 비활성 "저장됨"으로 바뀌어 포커스가 body로 간다.
- TabNav가 시트의 inert 범위 밖에 있어서, 시트가 열린 동안에도 키보드 Tab으로 탭에 갈 수 있다. 근본 해결은 네이티브 `<dialog>`의 `showModal()`이다.
- 훅 시그니처가 스펙 계약과 다르다. `useListings(store)`, `useDraft(store)`처럼 스토어를 인자로 받는다. 주입을 위한 선택이었다.
- 수도권 비규제·무주택과 비수도권·무주택 셀의 `effectiveDate`는 S2 시행일(2025-10-16)을 썼다. note에 근거를 적었다.
- 다음 작업 후보: 부부 공유 저장(Cloudflare D1 + Access, 사용자 요청), DSR, 부대비용 직접 입력, 서민·실수요자 우대(U1).

## 규칙 제안

log의 `놓침`과 반복된 문제에서 나온 후보다. 지침 파일은 고치지 않았고, 사용자가 판단한다.

1. **경계 예시는 반올림과 내림이 갈리는 값을 포함한다.** AC-1 내림 예시(69999.3)가 floor와 round를 구분하지 못해서 변이가 살아남았다. `CLAUDE.md` 후보 문구: "수치 계산의 테스트 예시에는 소수점 이하가 .5 이상인 경우를 하나 이상 넣는다."
2. **에이전트의 임시 파일은 `src/` 밖에 둔다.** tester가 `src/test/zzprobe.test.ts`를 만들었다 지우는 사이에 종료 전 검증 hook이 돌아 ESLint가 실패했다. 후보는 두 가지다.
   - `CLAUDE.md`: "임시·탐색용 파일은 scratchpad에 만든다."
   - hook: `src/` 아래에 `zz*` 파일을 만들면 막는다.
