# 정렬 방향 · 마지막 보기 기억 · 예산 동기화

## 결과

저장 목록 정렬 버튼을 다시 누르면 방향이 바뀌고, 마지막 정렬·방향·보기를 기억한다. 로그인하면 예산이 계정에 저장돼 어느 브라우저(카카오톡 인앱, 사파리)에서든 같다.

## 태스크별 결과

1. 정렬 방향 전환 + 기억 — 완료
2. 예산 서버 API(`users.budget`, `/api/budget`) — 완료, 원격 마이그레이션 0003 적용(기존 users 2·listings 20 그대로, budget 모두 NULL)
3. 로그인 사용자의 예산 출처·첫 로그인 이전 — 완료

## 팀이 내린 결정

- [ADR-025](../decisions/025-sort-order-budget-sync.md): 예산은 `users.budget` 컬럼, 주소 우선·없는 값만 기억, 방향은 별도 `order`. 사용자 요청(속도)으로 스펙 검토 라운드 생략
- 되돌림: 계정 스펙 U8 "예산은 기기별" → 로그인 시 계정 동기화

## 수용 기준

- AC-0 기존 데이터 보존: 통과 — 기존 키 원문 불변(fe 헤드리스), 옛 주소 `?sort=…&view=…` 그대로, 원격 마이그레이션 전후 기존 행 그대로. 새 키 `listings-view`, `budget-imports`
- AC-1~3 정렬·기억: 통과(360px 헤드리스) · AC-4 예산 API: 통과(로컬 curl) · AC-5~7 예산 출처: 통과(헤드리스 55항목). 실제 탭 전환·실기기 오프라인은 미검증
- qa off(사용자 지시), 새 테스트 없음, 기존 720개 통과

## 사용자 확인 필요

- U1 정렬 기본 방향(자기자금 적은 순, 최근 최신 먼저, 가나다 가→하), U2 계산 불가 매물은 늘 맨 뒤, U3 앱을 열 때 마지막 탭까지 기억할지, U4 정렬 기억은 브라우저별, U5 로그인 중 바꾼 예산은 계정에만(로그아웃하면 기기 예산)

## 남은 이슈

- 저장소에 쓸 수 없는 브라우저는 예산 이전을 매번 다시 시도(서버가 덮지 않아 계정 값은 안전)
- 매물이 0개면 예산 줄이 안 보이는 기존 동작 그대로
