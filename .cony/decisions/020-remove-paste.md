# ADR-020 텍스트 붙여넣기를 스크린샷 OCR로 바꾼다

- 상태: 채택
- 맥락: 태스크 3(네이버부동산 공유 텍스트 붙여넣기)은 "앱 공유 텍스트에 가격이 들어 있다"는 가정(U3, 실제 샘플 없음) 위에 만들었다. 사용자가 확인해 보니 네이버부동산 앱 공유 메뉴에는 복사가 없다. 링크로 가져오기는 하지 않는다(ADR-019).
- 선택지: A 삭제 / B 링크 저장으로 교체 / C 스크린샷을 올리면 브라우저 안에서 OCR로 글자를 읽어 채움
- 의견: 사용자(C 선택, "OCR로 해보자") / 리드(C, 네이버 앱에서 쓸 수 있는 유일한 경로이고 네이버 서버에 접근하지 않음)
- 결정: C. 텍스트 입력(textarea) 경로는 없애고 이미지 입력으로 바꾼다. 가격·면적 파서(parseKoreanPrice, parseListingShareText의 규칙)는 OCR 결과 텍스트에 재사용한다. 세부(라이브러리, 언어 데이터 위치, 화면)는 OCR 스펙과 후속 ADR에서 정한다.
- 이유: 앱 사용자에게 실제로 쓸 수 있는 입력 경로를 준다. 이미지는 사용자가 직접 올린 것이고 기기 밖으로 보내지 않는다.
- 뒤집을 조건: 실제 스크린샷 인식률이 낮아 직접 입력보다 느릴 때.
