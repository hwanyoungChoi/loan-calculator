# ADR-025 예산 저장 위치, 정렬 주소와 기억의 우선순위, 방향 표기

- 상태: 채택
- 맥락: 정렬 방향 전환·마지막 보기 기억·로그인 예산 동기화를 붙이면서 서버 예산 위치와 주소/기억 우선순위를 정해야 했다. 스펙: [sort-order-budget-sync](../specs/sort-order-budget-sync.md)
- 선택지: D1 A `users.budget` 컬럼 / B `budgets` 테이블 / C `user_settings` · D2 A 주소 우선, 없는 값만 기억 / B 기억 우선 · D3 A 별도 `order` 파라미터 / B `sort=name-desc`
- 의견: pm(전부 A). 작은 변경이라 사용자 요청(속도)에 따라 be·fe 스펙 검토 라운드는 생략하고 리드가 판정했다.
- 결정: D1 A, D2 A, D3 A
- 이유: 사용자당 값 하나라 컬럼이 가장 단순하고 기존 행은 NULL이라 AC-0에 안전하다(D1). 옛 `?sort=…&view=…` 주소가 지금처럼 열린다(D2·D3).
- 뒤집을 조건: 예산 외 계정 설정이 늘면 D1 C를 본다.
- 제품 기본값(사용자 확인 전): 스펙 U1~U5.
