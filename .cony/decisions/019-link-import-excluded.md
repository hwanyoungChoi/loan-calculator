# ADR-019 매물 링크 가져오기는 하지 않는다 (사이트가 자동 접근을 명시적으로 금지)

- 상태: 채택
- 맥락: 사용자가 네이버부동산·호갱노노·KB부동산 매물을 끌어오길 원했고(U2), 리드가 "붙여넣은 링크 한 건만 그때 가져오기"로 범위를 좁혀 실현 가능성을 확인했다(2026-10-22).
- 선택지: A 제외하고 붙여넣기 자동 채움(태스크 3)으로 대체 / B 링크 한 건 서버 fetch / C 브라우저 위장 등으로 차단 우회
- 의견: planner(A 추천, 공개 API 없음·DB권 판결 보도) / 리드 확인 결과(아래)
- 확인 결과(각 사이트 robots.txt를 1회씩 요청):
  - land.naver.com: `User-agent: *` → `Disallow: /` (첫 화면만 Allow)
  - hogangnono.com: "Crawling Hogangnono is prohibited unless you have express written permission." 지정 검색엔진만 허용
  - kbland.kr: `User-agent: *` → `Disallow: /`, 일부 검색·AI 크롤러만 허용
- 결정: A. 매물 페이지 요청은 하지 않았다. C(우회)는 고려하지 않는다.
- 이유: 세 사이트 모두 일반 자동 접근을 명시적으로 금지한다. 한 건이라도 우리 서버가 요청하면 자동 접근이다. 공개 API도 없어 예고 없이 깨진다.
- 뒤집을 조건: 사이트가 공식 API·제휴를 제공하거나 서면 허가를 받을 때.
- 다음 단계 후보: 매물에 원본 링크(URL)만 저장해 두고 눌러서 여는 기능(서버 요청 없음).
