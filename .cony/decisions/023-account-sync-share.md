# ADR-023 계정 동기화·공유 링크의 저장 위치, 라우트, 목록 구조, 세션

- 상태: 채택
- 맥락: 카카오 로그인으로 기기 간 저장 유지, 기존 로컬 데이터 이전, 목록·매물 공유(값만 복사)를 붙이면서 공유 데이터 위치·링크 형식·로그인 상태의 목록 구조·서버 저장 형태·세션 방식을 정해야 했다. 스펙: [account-sync-share](../specs/account-sync-share.md)
- 선택지:
  - D1 공유 데이터: A D1 스냅샷+토큰 / B URL에 인코딩
  - D2 링크: A `#/share/{token}` / B `/s/{token}`
  - D3 로그인 상태 목록: A 서버 원본 + react-query 훅 / B 로컬 우선 + 동기화 큐 / C 기존 동기 스토어에 서버 구현
  - D4 서버 매물: A 행마다 JSON 본문 / B 필드별 컬럼
  - D5 세션: A D1 sessions + HttpOnly 쿠키 / B 서명된 무상태 쿠키
- 의견: pm(전부 A 추천) / be(D1·D2·D3·D5 찬성, D4 조건부: id·시각 검증, 메모 보존 단일 UPDATE) / fe(D1·D4·D5 찬성, D2·D3 조건부: 라우트 4곳 동시 수정, 출처 상태와 이전 중 로딩)
- 검토 원문: [be](../reviews/20261023-1140-be-spec-account-sync-share.md) · [fe](../reviews/20261023-1140-fe-spec-account-sync-share.md)
- 결정: D1~D5 모두 A. 아래 조건을 스펙에 반영한다.
  - 공유 검증 함수는 DOM 타입과 `@/` 별칭 없는 새 파일로 빼고, 전이 의존도 상대 경로로 바꿔 `tsc -b`(worker)를 통과시킨다.
  - 서버 경계 검증: id `^[A-Za-z0-9_-]{1,64}$`, `createdAt`·`updatedAt`은 기존 ISO 규칙. 위반은 400 `invalidParams`. 사용자당 매물 500개 상한.
  - import는 클라이언트가 100개 단위로 나눠 보내고, 서버는 한 요청을 `json_each` 한 문장(또는 소량 다중 행 배치)으로 넣는다. `imported`는 `meta.changes` 합.
  - 공유 생성 상한은 100개·128KB, 바이트는 스트림으로 센다. 만료 공유는 GET에서 지우지 않고 POST 때 정리한다. 클라이언트는 410·404를 모두 "사라진 링크"로 본다.
  - 표에 없는 `/api/*`는 JSON 404, 메서드가 틀리면 405.
  - 메모는 `PATCH /api/listings/{id} { memo }` 전용으로 고친다(전체 PUT으로 다른 기기의 값을 되돌리지 않게). PUT은 메모를 바꾸지 않는 단일 UPDATE.
  - 클라이언트 출처 상태는 `loading | loggedOut | loggedIn | error`. loading이면 쓰기를 기다리고 error면 막으며 로컬로 몰래 폴백하지 않는다. 로그아웃·401 때 목록 캐시를 지운다.
  - 이전이 끝날 때까지 목록은 로딩으로 두고, 실패하면 안내한다. 공유 응답은 클라이언트에서 같은 검증 함수로 다시 검증한 뒤에만 보이고 추가한다.
  - 로그인 안내 쿼리는 `Route`에 넣어 `useHashRoute`의 정규화로 지워지지 않게 하고, "추가했습니다"·"옮겼습니다" 알림은 메모리 상태로 넘긴다. 공유 라우트는 `{ name: "share", token }`, 토큰 대소문자 유지.
  - 새 테스트는 쓰지 않되, 바뀐 구조로 깨지는 기존 테스트는 고쳐 `pnpm test`를 통과시킨다.
- 이유: 만료·끊기에는 서버 상태가 필요하고(D1), 해시 라우트는 서버 라우팅을 건드리지 않으며 토큰이 Referer에 남지 않는다(D2). 서버 원본 + react-query는 CONVENTIONS의 API 훅 규칙과 맞고 실패가 그 자리에서 보인다(D3). 매물 형식이 이미 JSON 검증 함수로 정의돼 있어 JSON 본문이 가장 단순하다(D4). 로그아웃 즉시 폐기가 된다(D5).
- 뒤집을 조건: 오프라인 쓰기가 요구되면 D3 B(로컬 우선 + 큐)를 다시 본다. 사용자·매물이 크게 늘어 JSON 조회가 느려지면 D4 B를 본다.
- 제품 기본값(사용자 확인 전): 스펙의 U1~U11. 특히 이전은 자동이되, 이 기기에서 이미 다른 계정으로 이전한 기록이 있으면 한 번 묻는다(fe 제안).
