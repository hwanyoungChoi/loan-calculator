# ADR-022 LTV 70% 기본, 취득세·중개보수를 자기자금에 포함, 목록에서 수정·이름순 정렬

- 상태: 채택
- 맥락: 요청자 피드백(사용자 전달) — 70% 기본, 중개보수·취득세 자동 계산해 자기자금 포함, 목록에서 수정, 가나다순, KB시세 자동 조회. ADR-006(부대비용 제외)·ADR-009/013(보수적 기본값)을 사용자가 뒤집었다.
- 선택지: 스펙 D1~D8 각 A/B/C
- 의견: pm(D1 A, D2 A, D3 A, D4 A, D5 A, D6 A, D7 B, D8 B) / fe(전부 찬성·D7 조건부: 중과+85㎡ 미확인이 자기자금 전체를 지우지 않게, 카드 안 버튼 중첩 금지, 이름 바꾸기 시트 문구와 isSameAsListing 단일화) / qa(조건부: 중개보수 구간 경계 행 추가, 미확인은 상수 null 기준, ownFunds 연결 단언)
- 검토 원문: [fe](../reviews/20261022-1410-fe-spec-fees-and-default-ltv.md) · [qa](../reviews/20261022-1410-qa-spec-fees-and-default-ltv.md)
- 결정:
  - D1 A: draft 기본 customLtv "70"(새 계산·스크린샷 적용 후에도 70). 규제 LTV는 나란히 표시.
  - D2 A: src/lib/constants/purchaseCosts.ts(기준일·출처), Regulations에 합쳐 prop 하나.
  - D3 A: 입력·표시·저장은 만원 정수, 세금·보수는 원 단위 정수로 계산 후 항목별 만원 올림(ADR-002 보강).
  - D4 A: 주택 수·조정대상지역은 기존 입력에서 유도, "전용 85㎡ 초과" 스위치 하나 추가(선택 필드 isAreaOver85?, ADR-012 방식).
  - D5 A → 뒤집힘(사용자, 2026-10-22): 중개보수는 상한 요율 기준 추정, 부가세 제외("부가세 별도" 표시).
  - D6 A: 생애최초 감면은 계산에 넣지 않고 안내만.
  - D7 B: 카드 "수정" 버튼 + "OO 수정 중" 배너 + "이름 바꾸기". 카드 본체와 버튼 영역을 구조로 분리.
  - D8 B: KB시세는 가져오지 않음(공식 무료 API 없음, kbland robots Disallow — ADR-019). 안내 + "이 단지 실거래가 보기" 연결. 단지별 KB시세 기억은 다음 단계.
  - 미확인 처리: 상수 값이 null일 때만 unconfirmed(중과 시 농특세 null). 이때 자기자금 전체를 "—"로 지우지 않고 농특세만 뺀 값을 "농특세 미확인" 표시와 함께 보여 준다.
  - 6~9억 세율 반올림은 law.go.kr 원문으로 확정(소수점 이하 다섯째 자리 반올림 → 넷째 자리).
- 이유: 요청자의 실제 사고방식(낮은 금액 × 70%, 부대비용 포함 현금)에 맞추고, 법정 수치는 출처와 기준일을 단 한 파일에 둔다.
- 뒤집을 조건: 요청자가 규제 LTV를 기본으로 원할 때, 세법·중개보수 규정이 바뀔 때(상수 파일만 수정).
